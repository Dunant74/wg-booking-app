Parfait 👍 voici un **résumé clair, structuré et orienté entreprise** des opérations **Java ↔ PostgreSQL (JDBC)**.

---

# 📚 🔗 1. Principe général

👉 Java communique avec la DB via **JDBC**

```text
Java → JDBC → Driver → PostgreSQL
```

---

# 🧱 2. Les objets essentiels

| Objet               | Rôle               |
| ------------------- | ------------------ |
| `Connection`        | connexion à la DB  |
| `PreparedStatement` | exécuter du SQL    |
| `ResultSet`         | lire les résultats |

---

# 🔄 3. Cycle classique

```java
Connection → PreparedStatement → Execute → ResultSet (si SELECT)
```

---

# 🔍 4. SELECT (lire des données)

```java
String sql = "SELECT name, email FROM users";

try (Connection conn = DatabaseConnection.getConnection();
     PreparedStatement pstmt = conn.prepareStatement(sql);
     ResultSet rs = pstmt.executeQuery()) {

    while (rs.next()) {
        String name = rs.getString("name");
        String email = rs.getString("email");

        System.out.println(name + " | " + email);
    }
}
```

👉 Méthode utilisée :

```java
executeQuery()
```

---

# ➕ 5. INSERT (ajouter)

```java
String sql = "INSERT INTO users (name, email) VALUES (?, ?)";

try (Connection conn = DatabaseConnection.getConnection();
     PreparedStatement pstmt = conn.prepareStatement(sql)) {

    pstmt.setString(1, "Alice");
    pstmt.setString(2, "alice@example.com");

    pstmt.executeUpdate();
}
```

---

# ✏️ 6. UPDATE (modifier)

```java
String sql = "UPDATE users SET email = ? WHERE name = ?";

try (Connection conn = DatabaseConnection.getConnection();
     PreparedStatement pstmt = conn.prepareStatement(sql)) {

    pstmt.setString(1, "new@mail.com");
    pstmt.setString(2, "Alice");

    pstmt.executeUpdate();
}
```

---

# 🗑️ 7. DELETE (supprimer)

```java
String sql = "DELETE FROM users WHERE email = ?";

try (Connection conn = DatabaseConnection.getConnection();
     PreparedStatement pstmt = conn.prepareStatement(sql)) {

    pstmt.setString(1, "alice@example.com");

    pstmt.executeUpdate();
}
```

---

# ⚠️ 8. Différence clé

| Méthode           | Usage                    |
| ----------------- | ------------------------ |
| `executeQuery()`  | SELECT                   |
| `executeUpdate()` | INSERT / UPDATE / DELETE |

---

# 🔒 9. Pourquoi `PreparedStatement` ?

👉 Toujours utiliser ça :

* protège contre **SQL injection**
* plus performant
* plus propre

```java
VALUES (?, ?)
```

---

# 🧼 10. Bonne pratique

👉 Toujours utiliser :

```java
try (Connection ... ) {
```

➡️ ferme automatiquement les ressources

---

# 🧠 11. Ce que tu dois retenir

👉 L’essentiel :

* JDBC = pont Java ↔ DB
* `Connection` = connexion
* `PreparedStatement` = exécution SQL
* `ResultSet` = lecture
* `executeQuery` vs `executeUpdate`
* toujours utiliser `?`
