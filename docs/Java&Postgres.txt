Parfait 👍 excellente démarche — comprendre **le fond** va vraiment te différencier en entreprise.

Voici un **mini cours clair et structuré** sur la connexion **Java ↔ PostgreSQL (JDBC)**

1. Qu’est-ce que JDBC ?

 **JDBC (Java Database Connectivity)** = API Java pour communiquer avec une base de données.

C’est une **interface standard** :

* Java → JDBC → Driver → Base de données

```text
Java code → JDBC → PostgreSQL Driver → PostgreSQL
```



 2. Le rôle du Driver PostgreSQL

Le driver est une **bibliothèque** qui permet à Java de comprendre PostgreSQL.

➡️ Sans driver → ❌ `No suitable driver`

👉 Avec Maven :

```xml
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <version>42.7.4</version>
</dependency>
```

---

# 🌐 3. L’URL de connexion

👉 Format :

```java
jdbc:postgresql://host:port/database
```

👉 Exemple :

```java
jdbc:postgresql://localhost:5432/wg_booking
```

| Élément    | Signification   |
| ---------- | --------------- |
| localhost  | machine         |
| 5432       | port PostgreSQL |
| wg_booking | base            |

---

# 🔑 4. Établir une connexion

👉 Classe clé :

```java
Connection conn = DriverManager.getConnection(URL, USER, PASSWORD);
```

👉 C’est le point d’entrée vers la DB

---

# 🧱 5. Les 3 objets essentiels JDBC

## 1. Connection

👉 ouvre la connexion avec la base

```java
Connection conn = ...
```

---

## 2. Statement

👉 exécute du SQL

```java
Statement stmt = conn.createStatement();
```

---

## 3. ResultSet

👉 contient les résultats

```java
ResultSet rs = stmt.executeQuery("SELECT * FROM users");
```

---

# 🔄 6. Lire les données

```java
while (rs.next()) {
    String name = rs.getString("name");
}
```

👉 `rs.next()` = ligne suivante
👉 `getString("colonne")` = valeur

---

# 🔁 7. Cycle complet JDBC

```java
Connection → Statement → Query → ResultSet → Close
```

👉 Exemple :

```java
Connection conn = ...
Statement stmt = conn.createStatement();
ResultSet rs = stmt.executeQuery("SELECT * FROM users");

while (rs.next()) {
    System.out.println(rs.getString("name"));
}

conn.close();
```

---

# 🧼 8. Bonne pratique : try-with-resources

👉 évite les fuites mémoire

```java
try (Connection conn = ...;
     Statement stmt = conn.createStatement();
     ResultSet rs = stmt.executeQuery(...)) {

    // code

}
```

# ⚠️ 9. Erreurs courantes

### ❌ No suitable driver

👉 driver non chargé (Maven)

---

### ❌ Connection refused

👉 PostgreSQL pas lancé

---

### ❌ Authentication failed

👉 mauvais mot de passe

---

# 🔥 10. Ce que JDBC NE fait PAS

👉 JDBC est bas niveau :

* pas de logique métier
* pas d’ORM
* pas de mapping automatique

👉 En entreprise, on utilise souvent :

* **Spring Boot + JPA / Hibernate**

---

# 🧠 11. Ce que tu dois retenir (important)

👉 Si tu retiens seulement ça :

* JDBC = pont Java ↔ DB
* Driver obligatoire
* URL + user + password
* 3 objets clés :

  * `Connection`
  * `Statement`
  * `ResultSet`
* toujours fermer les ressources
